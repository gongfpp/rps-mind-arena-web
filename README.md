# 拳局 · RPS Mind Arena · Web

[立即游玩](https://gongfpp.github.io/rps-mind-arena-web/) · 0.7.0-alpha.3 · 简体中文

月下三路，一拳定局。像素风卡牌构筑冒险：侦察对手习惯，部署石头、剪刀、布，在一章十二站中构筑牌组。

本仓库专门分发网页运行文件及第三方许可证。开发源码在独立私有仓库维护，本仓库没有该源码仓库的 Git 历史。Godot 运行包不是加密格式。

## 游玩

推荐桌面浏览器、键盘和鼠标。首次载入需要下载引擎和素材，点击“进入游戏”后等待加载完成。

- 拖动卡牌到左、中、右路，也可先点卡牌再点位置。
- `1–5` 选牌，`A / S / D` 部署，`Space` 揭牌或继续。
- 剧情出现选项时用数字键明确选择，或用 `Tab` 聚焦后按 `Enter`。
- `Esc` 暂停；设置可调音量、演出速度和减少动态效果。

有效操作后自动保存。存档只属于当前网站与浏览器，清除网站数据或隐私模式可能导致丢失；不同网站地址的旧存档不会自动迁移。当前没有跨设备云存档。游戏不上传玩家存档，页面与文件访问由 GitHub Pages 提供。

当前第一章包含 24 张牌、7 种敌人和十二站；没有第二章入口。移动触控、屏幕阅读器和外部玩家盲测尚未验收。

## 发布与许可

`web/` 保存完整导出包，推送到 `main` 后由 GitHub Actions 发布到 Pages。版本与构建来源见 [发布清单](web/release-manifest.json)。
